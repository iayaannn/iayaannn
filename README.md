### ☁️ CloudVault — Secure Cloud File Storage

A cloud-based file storage platform built around AWS services and REST APIs.

**Built With**

`HTML` `CSS` `JavaScript` `AWS S3` `Lambda` `API Gateway` `DynamoDB` `IAM` `CloudWatch`

**What I Built**

* Authenticated file upload and download
* File preview and metadata management
* REST API based architecture
* Cloud storage using Amazon S3
* Serverless backend using AWS Lambda
* API management through API Gateway
* Metadata storage using DynamoDB
* Access control using IAM
* Monitoring through CloudWatch
